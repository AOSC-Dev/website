---
title: Is AOSC OS Right for Me?
---

AOSC OS is an operating system using dpkg package manager, with Linux kernel and various components built and maintained independently. Primarily designed for personal devices, AOSC OS targets users with some prior Linux experience. Besides, AOSC OS dedicates to deliver an out-of-the-box experience, simplified system management, and a reliable working environment.

AOSC OS is one of many Linux distributions. Therefore, when choosing a Linux distribution, you might be struggling with the "Decidophobia". This article aims to introduce AOSC OS from multiple perspectives to help you make a decision.

## Design Pinciples

AOSC OS is designed base on the following goals and principles:

-   Avoid unnecessary package splitting, one package for one application.
-   Provide a seamless out-of-the-box experience for users of all languages.
-   Treat open-source and proprietary software equally.
-   Prioritize system reliability.
-   Deliver similar functionality and user experience on different architectures.

## Key Advantages

The main advantages of AOSC OS include:

-   Quick deployment and out-of-the-box experience.
-   Simple and straightforward system management.
-   Maintainers dedicated to providing technical support.
-   Strong support for proprietary and commercial software.
-   Out-of-the-box multilingual support.
-   Comprehensive hardware driver support.
-   Pre-configured power management.
-   Pre-installed network connectivity tools for specific regions.
-   Good Windows application compatibility via Wine.
-   Consistent and well-optimized experience across architectures.

## Key Disadvantages

At the same time, AOSC OS has the following main drawbacks for your reference:

-   Relatively large system footprint, requiring more storage than some other distributions.
-   Lack of multilib and multiarch support, making cross-architecture development cumbersome.
-   Smaller software repository.
-   Limited support for third-party commercial software.
-   Limited maintainer resources, potentially resulting in slower responses to bug fixes and security updates.
-   Includes pre-installed proprietary and non-free software.

## Recommended Use Cases

AOSC OS is well-suited for the following scenarios:

-   Personal and home use.
-   Devices with enough storage and stable internet connectivity.
-   Users who want easy deployment and prefer an out-of-the-box experience.
-   Software update speed is not critical.
-   Power-sensitive and thermally-sensitive devices such as laptops.
-   You are interested in contributing to AOSC OS development.

## Not Recommended For

We do not recommend deploying or using AOSC OS in the following scenarios:

-   Users with no prior Linux usage or administration experience.
-   Requires lightweight or highly customizable systems.
-   Requires rapid response times for software updates.
-   Commercial or high-reliability environments.
-   Public clouds, virtual servers or other environments where storage are expensive.
-   Users who are sensitive to non-free software.
