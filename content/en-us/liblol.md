---
title: libLoL Compatibility Layer
---

libLoL (LoongArch on LoongArch) is a runtime designed to provide Old World ABI compatibility. The Old World ABI is commonly used by commercial software designed for Loongson's Loongnix reference distribution and UnionTech UOS, such as Tencent QQ for Linux, Kingsoft WPS for Linux, and the Loongson Browser. Since these applications have not yet been ported to the New World ABI, this runtime aims to provide convenience for New World distribution users to run the applications above.

After installing libLoL, you can directly install and run Old World ABI applications.
